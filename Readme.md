<br/>

**SuriLens** is a Node.js backend observability tool I built to help developers understand application execution, inspect request flows, and debug backend behavior.

**Core capabilities**

- **Execution Graphs:** understand application execution flows.
- **Visual Replay:** inspect execution behavior through a visual debugging workflow.
- **Distributed Tracing:** support for W3C Trace Context.
- **Framework Integration:** middleware for supported Node.js frameworks.
- **Sensitive Data Masking:** protect sensitive information in captured data.
